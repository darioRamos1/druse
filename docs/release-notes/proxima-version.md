## Privacidad y actualizaciones

La búsqueda automática de actualizaciones requiere autorización. Si ya usabas Druse, dejarás de recibir avisos automáticos hasta que elijas «Buscar actualizaciones al abrir Druse» en Preferencias → Acerca de. Puedes buscar manualmente en esa misma sección y desactivar la búsqueda automática cuando quieras.

Preferencias → Privacidad explica el almacenamiento local, las conexiones a bases de datos y proveedores de IA, las consultas de versión a GitHub y el diagnóstico. También está disponible en la web de Druse cuando se publique la landing actualizada. El aviso sigue provisional mientras se completan los datos del responsable y las comprobaciones de instalación y tráfico.

Antes de compartir un diagnóstico, revisa el ZIP: aunque se filtran credenciales, los errores pueden contener nombres de servidores, bases o tablas.

Este documento no anuncia una release publicada ni firma Authenticode. Asignar versión, enlaces y resultados de validación al preparar la publicación.
