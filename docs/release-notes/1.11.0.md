# Druse 1.11.0

Las ediciones **Completa**, **Sin Informix** y **Comunidad** están disponibles
para Windows x64 con instalador y ZIP sin instalación. La landing ofrece las
descargas de cada edición y se actualiza al publicar una versión comprobada.

- **Comunidad:** PostgreSQL, SQL Server, MySQL/MariaDB y SQLite, sin
  controladores de Oracle, IBM ni IKVM.
- **Completa:** todos los motores de Druse, incluidos Oracle e IBM Informix.
- **Sin Informix:** incluye Oracle y omite el controlador de IBM Informix.

Para uso habitual, descarga el instalador de tu edición. Para ejecutar sin
instalación, extrae el ZIP completo y abre `druse.exe`; requiere Microsoft Edge
WebView2 Runtime instalado. No necesitas instalar .NET ni Node.js. Las
conexiones y preferencias se guardan en tu perfil de Windows: copiar la carpeta
portable a otro equipo no las traslada.

Esta publicación reúne también las mejoras de contexto del chat incorporadas
después de la beta pública 1.3.0: selección de tablas y columnas, notas de
negocio, revisión del contexto antes de enviarlo, explicación de errores,
muestras de filas con ocultación de valores y planes estimados de SQLite.
Cada envío respeta los permisos del proveedor y permite revisar su contenido.

Los paquetes todavía **no tienen firma Authenticode**; Windows puede mostrar
SmartScreen. Las firmas `.sig` corresponden al actualizador de Tauri y no
acreditan al editor ante Windows. La validación completa de instalación y
tráfico en un Windows limpio sigue pendiente; los resultados automatizados no
equivalen a esa validación.

Comprueba el archivo descargado con `Get-FileHash -LiteralPath '.\NOMBRE-DEL-ARCHIVO' -Algorithm SHA256`
y compara el resultado con `SHA256SUMS.txt`. La publicación incluye inventarios
de contenido y evidencia del commit, las pruebas y los hashes de los paquetes.
