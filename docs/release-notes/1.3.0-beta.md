# Druse 1.3.0 — beta de Comunidad

Esta es una **versión de prueba para Windows x64** de la edición Comunidad. Incluye PostgreSQL, SQL Server, MySQL/MariaDB y SQLite; no incluye los controladores Oracle, IBM DB2 ni Informix. El código fuente, los avisos de terceros y las instrucciones de construcción están en el [repositorio público](https://github.com/darioRamos1/druse).

La aplicación permite consultar y administrar esas bases de datos desde el escritorio. Esta beta incorpora mejoras en resultados, navegación por teclado, historial de consultas y mensajes de error. Las comprobaciones automatizadas del paquete verifican que la API arranca sin los controladores excluidos y puede ejecutar una consulta SQLite.

**Estado de esta beta:** el instalador no tiene firma Authenticode ni aprobación de SignPath Foundation; Windows puede mostrar SmartScreen. Esta prerelease no entra en `releases/latest`, no incluye archivo `.sig` del actualizador y no se actualiza automáticamente desde la aplicación. La instalación, actualización, desinstalación y el tráfico de red aún necesitan una prueba completa en Windows limpio. No se ha confirmado que SignPath acepte SNI ni WebView2 dentro de su programa.

Compara el SHA-256 del instalador con el archivo `SHA256SUMS.txt` adjunto a esta release antes de ejecutarlo. Comunica fallos a [druse.contacto@gmail.com](mailto:druse.contacto@gmail.com) o abre una incidencia en el repositorio. La [política de privacidad de la aplicación](https://darioramos1.github.io/druse/privacidad-aplicacion.html) describe los datos locales y las conexiones que se realizan por acción de quien la usa.
