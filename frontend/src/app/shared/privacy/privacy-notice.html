Qué se guarda en tu equipo

Druse guarda conexiones, historial SQL, fragmentos, diagramas y perfiles en una base local. En Windows se encuentra en %APPDATA%\Druse\druse.db. Las contraseñas de conexión y claves de proveedores de IA se guardan en el Administrador de credenciales de Windows.

Los registros y la caché se guardan en %LOCALAPPDATA%\Druse. Las exportaciones y respaldos quedan donde elijas. Una configuración personalizada de la carpeta de datos puede cambiar estas rutas. Protege también los archivos que exportes o compartas.

Cuándo salen datos del equipo

  • Bases de datos y SSH. Al conectarte se envían las credenciales, consultas y datos necesarios a los servidores que configures.
  • Actualizaciones. La búsqueda automática en GitHub está desactivada hasta que la autorices. Puedes cambiarla en Preferencias → Acerca de o buscar manualmente. GitHub recibe la dirección IP y las cabeceras de la petición; la consulta de versión no incluye tu SQL, resultados ni credenciales de bases de datos.
  • Asistente de IA. Al enviar una pregunta, el proveedor que configures recibe el texto y, según el contexto que elijas, el SQL abierto y la estructura de tablas. Druse no añade las filas de resultados al contexto; cualquier dato que pegues en la pregunta sí se enviará. Revisa el contenido antes de enviarlo. Un programa de IA local puede conectarse a servicios externos según su propia configuración.
  • WebView2. Druse utiliza este componente de Microsoft. Su instalación, actualización y comportamiento de red dependen de Windows y de la configuración del componente.

No hay cuentas de usuario de Druse ni integraciones de publicidad o analítica identificadas en el código revisado. La API que utiliza la aplicación se ejecuta en tu equipo y escucha en la interfaz local.

Diagnóstico y soporte

El diagnóstico contiene registros y datos de versión y sistema. Druse aplica filtros para ocultar credenciales, pero los mensajes de error pueden incluir nombres de servidores, bases o tablas. Revisa el ZIP antes de compartirlo y retira datos sensibles. Guardarlo no lo envía automáticamente al equipo de Druse.

Contacto: druse.contacto@gmail.com. Si escribes, Gmail procesa tu dirección, mensaje y adjuntos. No incluyas contraseñas, claves ni datos de clientes. Los datos legales del responsable y las condiciones de conservación de las solicitudes siguen pendientes de confirmar.

Al desinstalar

Puedes usar la opción de desinstalación de Windows. Todavía se está verificando qué datos y credenciales conserva ese proceso; no asumas que elimina todo tu historial. Haz una copia de los datos que quieras conservar y consulta el estado de esta comprobación antes de borrar carpetas o credenciales manualmente.

Este aviso corresponde a la aplicación de escritorio. La web tiene su propio aviso de privacidad y cookies. Los servidores y proveedores que elijas tienen sus propias políticas de tratamiento.
