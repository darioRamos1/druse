ALGUNAS RESPUESTAS

Antes de empezar.

¿Qué bases de datos puedo conectar?+

Druse admite PostgreSQL, SQL Server, MySQL, MariaDB, SQLite, Oracle e Informix. La disponibilidad de Informix depende de la edición instalada.

¿Druse funciona en el navegador?+

Druse es una aplicación de escritorio. Esta página presenta la aplicación; para conectar tus bases de datos necesitas instalarla en tu equipo.

¿Necesito instalar herramientas adicionales?+

El instalador de Windows incluye los componentes de ejecución de Druse. No necesitas instalar .NET ni Node.js. Solo debes tener acceso a la base de datos con la que quieras trabajar.

¿Dónde se guardan mis contraseñas?+

Las contraseñas se guardan en el almacén seguro del sistema operativo. Si no está disponible, Druse te pide la contraseña en cada conexión en lugar de guardarla sin protección.
